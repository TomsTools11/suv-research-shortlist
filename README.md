# SUV Research Shortlist

Interactive dashboard comparing four vetted used mid-size SUVs for a family purchase ($10,000-$18,000): Toyota Highlander, Honda Pilot, Chevrolet Traverse, and Hyundai Santa Fe XL. Each card has a photo, price range, safety ratings, rear legroom, pros, cons, and watch-outs, plus sorting, filters, favorites, and a side-by-side comparison table.

Static page (single `index.html`), deployed on Vercel from this repo.
